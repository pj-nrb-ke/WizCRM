# WizCRM commercial plans (MGT-006)

| Plan | Code | Audience | Key features |
|------|------|----------|--------------|
| **Lite** | `lite` | Internal pilot | Core CRM, basic desk, mobile field app |
| **Pro** | `pro` | Paying SMB | + AI insights, targets, hygiene, quotes, manager brief, web admin |
| **Enterprise** | `enterprise` | Full platform | + geofence, ERP sync, advanced security |

Seat limits and pricing are defined with ScaleGate (MGT-007). Feature flags are enforced in `shared/src/entitlements.ts`.
