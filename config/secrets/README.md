# Email secrets (Brevo)

1. Copy `brevo.local.example.txt` to `brevo.local.txt`, **or** place credentials at `docs/brevo.local.txt` (also supported).
2. Fill keys from [Brevo](https://app.brevo.com) → Transactional → SMTP & API.
3. Never commit `brevo.local.txt`.

See [docs/email-integration.md](../../docs/email-integration.md) for WizCRM setup and verification.
