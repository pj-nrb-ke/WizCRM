# WizCRM Mobile

React Native app (Expo, TypeScript) for Android and iOS.

## Commands

```bash
cd mobile
npm install
npx expo start
```

Press **`a`** for Android emulator or scan the QR code with Expo Go on a device. See [`../MOBILE_DEV.md`](../MOBILE_DEV.md).
